# InterviewAce AI - Design System

## Vision

InterviewAce AI is a premium AI-powered interview preparation platform.

The design should feel modern, minimal, professional, and trustworthy.

Inspiration:

- Linear
- Vercel
- Clerk
- Notion
- Stripe Dashboard

Never look like a Bootstrap admin panel.
